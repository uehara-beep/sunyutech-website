# 01 自社プロダクト分析

サンユウテック株式会社コーポレートサイトの受注軸リニューアルにあたり、既存サイト（`index.html` / `company.html` / `service.html` / `works.html` / `contact.html`）から事実情報のみを抽出し、現状の強み・弱みを整理する。

---

## 1. このプロダクト（会社）が解決する課題（3本）

1. **大手ゼネコン現場の「特殊工法を任せられる協力会社が見つからない」問題**
   既存 `index.html` の Strengths セクションでは「株式会社NIPPO、株式会社前田道路など、大手建設会社様との継続的な取引実績」を明示し、`service.html` でも「大手建設会社様の協力会社として、また元請としての民間工事において、現場のニーズに応じた確かな施工をご提供」と表現。
   舗装・ウォータージェット・コンクリート補修の3工法を一社で受託できる協力会社は限られ、九州エリアで案件ごとに別業者を探す元請の負担を吸収するポジションを取っている。

2. **コンクリート構造物（橋梁・トンネル・床版）の劣化補修における「振動・騒音を抑えた施工」課題**
   `service.html` のウォータージェット工事節で「従来のブレーカーや削岩機によるはつり作業と比較して、振動・騒音が少なく、周囲への影響を最小限に抑えながら作業を行うことができます」と明記。
   `works.html` の実績「床版上面コンクリートはつり（九州自動車道管内）」「中空床版はつり（長崎自動車道管内）」「床版上面断面修復工（九州自動車道管内）」のように、高速道路の供用下補修というセンシティブな現場で実績を積んでいる。

3. **舗装〜下地処理〜断面修復〜表面保護まで「工程を分断せず一気通貫で受けられる体制不足」**
   `service.html` の3サービス節からは、ウォータージェット（劣化部除去・断面修復下地処理）→コンクリート補修（断面修復・表面保護）→舗装（オーバーレイ・新設）の各工程が同社内で完結する建付けになっていることが読み取れる。
   `company.html` の「保有機械」一覧（CONJET327 2台、NLB 35305DGF 2400bar 46L/min 2台、SB機械 4台、大型ミキサー 8台、大型バキューム 1台 等）も自社で施工リソースを保有して工程をつなぐ体制の裏付けになっている。

## 2. ターゲットのペインポイント（機能一覧から逆算）

### 受注側（ゼネコン施工管理 / 元請技術部）

- **協力会社の「保有機械と人員の実体」が掴めない**
  競合の多くは保有機械を明示せず資格者数のみ羅列するが、サンユウテックは `company.html` の「保有機械」セクションで CONJET327 2台 / NLB 35305DGF 2台 / SB機械 4台 等を機種名と台数で明示している。これは元請技術部が「この現場、サンユウなら回るか」を即判断できる情報源。逆に既存サイトでは UFP（超高圧水）の出力スペックや WJ 適用範囲の説明が機械リストにのみ眠っており、サービス説明側に紐付けされていない点がペインとなる。

- **「九州エリアで実際にどの現場をやっているか」が分かりにくい**
  `works.html` の実績8件は「福岡県内」「大分県内」「熊本県内」「長崎県内」「九州自動車道管内」「長崎自動車道管内」と九州一円に分布するが、各カードは1〜2行・写真1枚で完結し、規模感（約7,000m²/約30,000m²等）以外の工期・工事条件・元請構成が読めない。元請が「自社の次案件と類似実績はどれか」を引き当てる導線が弱い。

- **問い合わせフォームの種別が事業者向けに整理されていない**
  `contact.html` のお問い合わせ種別 select は「お見積りのご依頼／ご相談・ご質問／舗装工事について／ウォータージェット工事について／コンクリート補修工事について／協力会社のご提案／採用について／その他」と8項目。受注側目線では「工種」と「役割（元請として依頼／協力会社の追加提案）」の2軸が混在しており、緊急の見積依頼が他項目に埋もれる構造。

### 採用候補者

- **採用情報ページが存在しない**（既存5ページに採用ページなし）。
  `contact.html` の問い合わせ種別に「採用について」が項目だけ存在し、受け皿として宙ぶらりん。求職者は職種・必要資格・想定給与・社風が分からないまま電話せざるを得ない。

- **「どんな現場をどんな道具でやっているか」が現場志望者に届きにくい**
  `images/hero-1.jpg` 〜 `hero-8.jpg`、`work-*.jpg` の写真資産はあるが、各写真の説明が works.html のカード上の1行に留まり、現場の雰囲気・チーム規模・夜間/昼間といった働き方ファクターが言語化されていない。

### 既存取引先

- **会社の最新動向（資格更新・新規導入機械・新規工法）を確認する場所がない**
  `company.html` の代表挨拶以外に動的なお知らせ枠が存在せず、長く付き合っている取引先が「最近のサンユウは何ができるようになったか」を測れない。
  Footer Copyright が「2024 サンユウテック株式会社」となっており（2026年5月時点）、サイトの鮮度感も弱い。

## 4. 既存サイトの弱点（受注軸視点）

- **弱点1: 取引先の社名が「各社」表記に丸められており、信頼の根拠が弱い**
  `index.html` Strengths にはNIPPO・前田道路の社名が出るが、`index.html` Trust セクション・`company.html` 主要取引先・`works.html` Partners はすべて「大手道路ゼネコン各社／地場ゼネコン各社」止まり。受注判断する元請にとっては「他にどこと取引しているか」が直接の信頼指標になるため、社名の見える化不足は致命的。

- **弱点2: 施工実績の情報粒度が浅く、案件マッチングに使えない**
  `works.html` の8件は「地域 / 数量 / 下請」の3情報のみで、工期・元請名・適用工法の組み合わせ・課題と解決が記載されない。`section` 末尾に「※施工写真は順次追加予定です。掲載している実績は一部となります」とエクスキューズが入っており、リードを掴む前提のページ設計になっていない。

- **弱点3: 受注リード（見積依頼）の優先導線がCTAとして弱い**
  `contact.html` の form アクション属性は `action="#"`（送信先未設定）。フォームが実質機能しない静的状態。
  またヒーロー（`index.html`）の主CTAは「お問い合わせ」「事業内容を見る」の2択で、見積依頼に特化したラベルがない。
  問い合わせ種別 select も「お見積りのご依頼」が「ご相談・ご質問」と並列のため、緊急度の高い見積依頼が他種別に埋没しやすい。

- **弱点4: ブランドが「オレンジ単色」に依存し信頼業界の文脈に弱い**
  `README.md` カラーパレットで `--primary-orange: #E67E22` を主軸に据え、ヒーロー・CTA・H2英字スタイルすべてがオレンジ。BRIEF.md の方針（ネイビー #0B2545 主・オレンジ差し色）と乖離。建設業の受発注担当が「真面目さ・専門性」を読み取りにくい配色設計。

- **弱点5: 採用導線が「項目だけ」存在して受け皿ページが無い**
  `contact.html` の問い合わせ種別 select に `<option value="recruit">採用について</option>` を設けているが、採用情報ページ自体が5ページ構成に含まれていない。求職者がサイト内回遊で職務理解を深められない。

- **弱点6: サイト鮮度の不明瞭さ**
  全ページの footer copyright が「&copy; 2024 サンユウテック株式会社 All Rights Reserved.」で固定。`README.md` の Last Updated は 2026-03-02 のため、コンテンツ更新と表記が一致しておらず「更新されているサイトか」の判断が難しい。
