## 2. 既存の `.htaccess` を退避する

- [ ] `/public_html/sunyutech.jp/.htaccess` をパソコンにダウンロードして保管

**確かめ方**: 手元にファイルが保存されていること

> `.htaccess` は隠しファイルです。FTPソフトの設定で
> 「隠しファイルを表示する」を有効にしてください。
>
> **ファイル自体が無ければ、この手順は飛ばして構いません。**
> 中身がある場合は、次の手順で上書きしないよう注意が必要です。

## 3. 動作に必要なファイルだけ先に上げる

**HTMLはまだ上げません。** 先にHTMLを入れ替えると、設定が終わるまでの間に
来た問い合わせがすべて失敗して失われます。

- [ ] `contact.php` をアップロード
- [ ] `contact-lib.php` をアップロード
- [ ] `contact-config.example.php` をアップロード
- [ ] `.htaccess` を配置

> ### ⚠️ `.htaccess` の扱い
>
> 手順2で退避したファイルに中身があった場合、**そのまま上書きすると
> 既存の設定（HTTPS化・www転送・エラーページ指定など）が消え、
> サイト全体が壊れる恐れがあります。**
>
> - 退避したファイルが**空、または存在しなかった** → そのまま上げてよい
> - 退避したファイルに**中身がある** → 既存の内容の末尾に新しい内容を
>   **追記**したものを手で上げる
>
> 判断に迷う場合は、退避したファイルの中身をお知らせください。
> 統合したものをお渡しします。
>
> `.htaccess` を次の手順より先に上げるのは、設定ファイルを作った直後に
> 保護されているかを確認できるようにするためです。

**確かめ方**: FTPソフトでこの4つが公開フォルダに見えること

## 4. 設定ファイルを作る

- [ ] サーバー上で `contact-config.example.php` を `contact-config.php` という名前でコピー
- [ ] 中身を編集して保存

編集するのは次の3行です。

```php
    'mail_to'     => '（問い合わせを受け取るアドレス）',
    'mail_from'   => 'no-reply@sunyutech.jp',
    'form_secret' => '（下記で作る文字列）',
```

`form_secret` は、いたずら送信を防ぐためのパスワードのような文字列です。
**40文字以上の、意味のない英数字**にしてください。他人に教える必要はありません。

SSH が使えるなら、次のコマンドで作れます。

```bash
php -r "echo bin2hex(random_bytes(32));"
```

使えない場合は、キーボードででたらめに打った長い英数字で構いません。

> **行末の `,` を消さないでください。** これが1つ欠けるとファイル全体が
> 読み込めなくなり、ページが真っ白になります。

**確かめ方**: ブラウザで https://sunyutech.jp/contact-config.php を開く

| 表示 | 判定 |
|---|---|
| 「403」「Forbidden」「アクセスが拒否されました」 | ✅ 正しく保護されています |
| 真っ白なページ | ⚠️ PHPは動いていますが `.htaccess` が効いていません。**お知らせください**（設定ファイルを公開フォルダの外へ移す方法に切り替えます） |
| ファイルの中身が文字として見える | ❌ **すぐに中断してご連絡ください**（秘密の文字列が漏れています） |

## 5. 残りのファイルを上げる

ここで初めてHTMLを入れ替えます。

- [ ] HTMLファイル・画像などをアップロード

> ### ⚠️ 同期（ミラーリング）機能を使わないでください
>

> という設定を使うと、**手順4で作った `contact-config.php` が消えます。**

>

> 除外対象に指定してください。
>
> `.htaccess` は手順3で配置済みです。ここでは触りません。

**確かめ方**: https://sunyutech.jp/contact/ を開いてフォームが表示される

> **古い内容が表示される場合があります。** サーバー側にキャッシュがあるため、
> アップロード直後は前のページが出ることがあります。
> ブラウザで「スーパーリロード」（Windows: `Ctrl` + `F5` / Mac: `Cmd` + `Shift` + `R`）
> を試し、それでも変わらなければ数分おいてから再度確認してください。

**あわせて確認**: トップページ（https://sunyutech.jp/）が正常に表示されること。
真っ白や「500」が出る場合は `.htaccess` の上書きを疑ってください。

## 6. 実際に送信してみる

- [ ] https://sunyutech.jp/contact/ からご自身宛に1件送る
- [ ] 受信箱に届いたか確認
- [ ] **迷惑メールフォルダも確認**

件名は `【HP問い合わせ】(入力したお名前)` です。

**確かめ方**

| 状況 | 対応 |
|---|---|
| 受信箱に届いた | ✅ 完了です |
| 迷惑メールに入った | ⚠️ 届いてはいます。お知らせください（送信設定を調整します） |
| 「送信しました」と出たのに届かない | ❌ お知らせください |
| 「サーバー設定が未完了です」と出る | ❌ 設定ファイルの**項目名**に不備があります。下記を確認 |
| ページが真っ白／「500」が出る | ❌ 設定ファイルの**書き方**が壊れています。下記を確認 |

### 「サーバー設定が未完了です」と出たとき

ファイルは読めているが、中身の項目名が違う状態です。

- `mail_to` を `mail_too` と書いている
- `mail_to` や `mail_from` がメールアドレスの形になっていない
- `form_secret` が空のまま、または例文のまま

> `mail_from` を `@sunyutech.jp` 以外にしても、このエラーは出ません。
> ただし**メールが迷惑メール扱いされて届かなくなる**ので、
> 必ず `no-reply@sunyutech.jp` のままにしてください。

### 真っ白／「500」になったとき

原因は2つ考えられます。

**1. PHP のバージョンが 8.0 未満**

管理画面の「PHP設定」で確認してください。これが原因の場合、
フォームだけでなく**サイト全体が真っ白**になります。

**2. 設定ファイルの書き方が壊れている**

フォームのページだけが真っ白なら、こちらです。

- 行末の `,` が抜けている
- `'` の閉じ忘れ
- 先頭の `<?php` を消してしまった

いずれも、退避しておいた `contact-config.example.php` からコピーし直すのが
確実です。

詳しい原因はサーバーのエラーログに**日本語で**記録されています。
コントロールパネルの「ログ」から確認できます。

## 困ったとき

**推測で設定を変えないでください。** 症状とエラーメッセージを
そのままお知らせいただければ、こちらで切り分けます。

設定を誤ると「送信できているように見えて実は届いていない」という、
外からは気づけない状態になり得ます。それが一番避けたい状況です。
